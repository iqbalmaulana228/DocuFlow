# DocuFlow

Document converter workspace with browser-local PDF/document tools.

## Features
- PDF merge, split, organize, extract/remove/rotate pages and other PDF utilities
- Image and document conversions
- Page thumbnail previews and live drag reordering
- End-user authentication configuration (email and Google provider)
- Client-side document processing; files are handled locally in the browser

## Hosted version
https://docuflow-document.hatchable.site

## Authentication note
Google OAuth on Hatchable requires a verified custom domain and Google OAuth client credentials configured in Hatchable Setup. The app currently uses the Hatchable auth provider declaration.
